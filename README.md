# Dalton Koh — portfolio

A static portfolio for GitHub Pages. No build or package installation is required.

## Edit

- `index.html`: the main page, project summaries, links and contact details.
- `style.css`: layout, colours and responsive styles.
- `script.js`: project details, media viewer and playground filters.
- `assets/`: images, compressed demo videos and the downloadable resume.

Run any static web server in this folder to preview it. For example, `python -m http.server 8765`.

## GitHub Pages

Publish the repository root from the `main` branch in Settings → Pages. The intended repository is `daltonkoh/daltonkoh.github.io`.

## Content notes

The main team projects are GrapeEngine / Echoes Below, Nookified and Beyond Us. Contribution summaries describe Dalton's work, not sole authorship of each project. Nookified is a demonstration prototype. Beyond Us is shown once as a featured project, with its gameplay recording.

Videos are shortened or compressed copies of the supplied recordings. The original files are not changed. Beyond Us uses the full supplied 90-second showcase; Echoes Below and the simulation use excerpts. No video downloads until its viewer is opened.

The pixel-art collage and level-design page are supplied school design material. Referenced game characters and third-party assets belong to their respective creators. Portfolio inclusion does not grant a licence to reuse them. Project media shows collaborative work.

Fonts use Google Fonts with local system fallbacks. The website remains readable if external fonts are unavailable.
